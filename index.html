RGB LED Status Indicator

LED Status Colors:

🔴 Red Blink - ERROR! No speed input (GPS or Water Speed)

🟣 Purple - System actively controlling motor

🟢 Green - GPS ready, system in standby

🟡 Yellow Blink - Searching for GPS signal

🟠 Orange Pulse - Phone/tablet connected via BLE

🔵 Blue - Water Speed only (no GPS)

🩵 Cyan - Both GPS and Water Speed valid

⚪ White Blink - System booting/initializing

Priority: Error states override all others. System state overrides data source indicators.

See RGB_LED_Status_Plan.md for complete technical details and troubleshooting.
