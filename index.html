⚙️ PID Tuning Quick Guide

Defaults work for most setups! Only change if:

  • Speed oscillates → Decrease Kp (try 0.30)
  • Won't reach target → Increase Ki (try 0.15)
  • Overshoots target → Increase Kd (try 0.10)
  • Too slow to respond → Increase Kp (try 0.70)

💡 Tip: Try adjusting Speed Smoothing first - often fixes issues without touching PID!

Reaction speed (default: 0.50)
Lower = gentler | Higher = more aggressive
Error elimination (default: 0.10)
Higher = reaches target exactly | Lower = tolerates small errors
Smoothness (default: 0.05)
Higher = smoother approach | Lower = faster changes allowed

RGB LED Status Indicator

LED Status Colors:

🔴 Red Blink - ERROR! No speed input (GPS or Water Speed)

🟣 Purple - System actively controlling motor

🟢 Green - GPS ready, system in standby

🟡 Yellow Blink - Searching for GPS signal

🟠 Orange Pulse - Phone/tablet connected via BLE

🔵 Blue - Water Speed only (no GPS)

🩵 Cyan - Both GPS and Water Speed valid

⚪ White Blink - System booting/initializing

Priority: Error states override all others. System state overrides data source indicators.

See RGB_LED_Status_Plan.md for complete technical details and troubleshooting.
